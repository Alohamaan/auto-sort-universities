# Status Dictionary

The deterministic engine and models use the following enums:

## MessageType
- `admissions`
- `marketing`
- `auto_reply`
- `unknown`

## EligibilityStatus
- `unknown`
- `eligible`
- `not_eligible`
- `requires_review`

## ApplicationStatus
- `unknown`
- `not_started`
- `in_progress`
- `submitted`
- `under_review`
- `offer`
- `rejected`

## DecisionKind
- `ignore`
- `review_queue`
- `pending_action`
